# Full-Stack Developer Assessment - LITWITS

## Objective
A production-ready full-stack web application demonstrating abilities in frontend, backend, database, authentication, APIs, and deployment.

## Technology Stack
- **Frontend**: React.js
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **Version Control**: Git/GitHub

## Requirements
1. **Authentication & Roles**: Admin & User roles, Login/Logout, Password Hashing, Role-based authorization.
2. **Dashboard**: Admin can manage users (view, add, edit, delete, search/filter, basic stats). Users can view and update their own profiles.
3. **Backend APIs**: REST APIs with auth middleware, validation, error handling.
4. **MongoDB Database**: Proper schema, efficient queries, indexing, and pagination.
5. **Security**: Password hashing, protected routes, secure DB credentials via environment variables, input validation.
6. **Deployment**: Deployed complete application with working frontend, backend, DB.
7. **GitHub**: Clean structure, meaningful commits, README, setup instructions.

## Project Structure
- `/backend`: Node.js/Express server and MongoDB models.
- `/frontend`: React.js application.
